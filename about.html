NLP Sentiment Analyzer

Natural Language Processing (NLP) is a branch of AI that helps computers work with human language.

This project demonstrates how text can be normalized, tokenized, scored with a sentiment lexicon, and classified as positive, neutral, or negative.

Technology Stack

  • Python
  • Flask
  • HTML + CSS + JavaScript
  • SQLite
  • Rule-based NLP

How it works

1User enters text.
2Python tokenizes and normalizes the text.
3Words are matched against positive/negative vocabularies.
4A sentiment score is calculated and classified.
5The result is stored in SQLite history.
